## Featured Projects

### SmartAir-Guardian

An IoT-based multi-gas monitoring and classification system that combines sensor data collection with machine-learning and deep-learning based classification. The project uses Python, TensorFlow/Keras, ESP8266, MQ-series gas sensors, DHT22, and Flask in a practical AI/IoT workflow.

### Civil Inspection / Building Inspection

A computer-vision project focused on building and facade inspection with opening detection. The work includes dataset auditing, duplicate detection, leakage checking, segmentation experiments, and evaluation on custom images using YOLO, U-Net, DeepLabV3, SegFormer, and SAM/SAM2 experimentation.

### Indian States Economic Growth / Climate Analysis

A data-science project exploring relationships between economic and agricultural indicators and environmental variables across Indian states. The work focuses on Python-based analysis, data visualization, and exploratory study of rainfall, groundwater, crop yield, and climate-related patterns without making causal claims beyond the data.
